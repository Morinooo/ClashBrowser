# Screenshots

No screenshots are committed yet. **Do not add fabricated, mock-up or
AI-generated screenshots of the app.** Only real captures from a running build
are acceptable.

Planned shots (add as PNG, 1080×2400 or similar, dark and light variants where
useful):

| File | Content |
|---|---|
| `home.png` | Local home page with logo, search box and shortcut icons |
| `browsing.png` | A normal page with the compact address bar and bottom bar |
| `proxy-panel.png` | Proxy centre: status, profile card, groups and node cards |
| `nodes.png` | Expanded policy group with node cards and latencies |
| `context-menu.png` | Long-press context menu on an image |
| `bookmarks.png` | Bookmark folder view |
| `dark-mode.png` | Dark appearance, optionally with a darkened web page |

How to capture:

1. Build and install `app-debug.apk` on an arm64 device.
2. Configure a subscription you are allowed to use, then switch to a node.
3. Capture with the device screenshot function.
4. **Redact** subscription URLs, node names/servers, traffic figures and any
   personal data before committing.
5. Add the files to this directory and reference them from the README
   (English and Chinese).

Until then, the README intentionally shows a placeholder instead of images.
