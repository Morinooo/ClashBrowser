# ClashBrowser v1.13.0

> 版本梳理：本 release 由旧 tag v1.6.7 重命名而来；APK 由原 commit 代码快照重建，
> versionName 已同步为 1.13.0（versionCode 18 不变）。新旧编号对照见 CHANGELOG。

First public release: a lightweight Android browser with an embedded mihomo
core. The browser proxies **only its own WebView** through the local mihomo
mixed port — no VPN permission, no system-wide proxy, no root.

## What's in this release

- Local home page with search box and up to 8 bookmark shortcuts
- Multi-tab browsing, compact address bar, fullscreen web video
- Embedded mihomo core run as a child process, with start/stop/restart and
  crash recovery
- Subscription import, profile cards (traffic / expiry / update time), policy
  groups, node switching and latency tests
- Run mode switching: Global / Rule / Direct
- Folder-based bookmarks with Netscape HTML import/export, history, incognito
- Long-press context menu: open in background / new tab, image actions, image
  gallery, page info, QR scan, mark ad domain
- DRM/EME and secure-keyboard hardening for real-world devices
- Lightweight host-list ad/tracker blocking

The full history is in [CHANGELOG.md](https://github.com/Morinooo/ClashBrowser/blob/main/CHANGELOG.md).
This release corresponds to app version **1.13.0** (`versionCode` 18).

## Requirements

- Android **8.0 (API 26)** or newer
- **arm64-v8a** device (this release contains only arm64 native libraries)
- An up-to-date Android System WebView
- Your **own** Clash-compatible subscription or configuration — the app ships
  with no subscription, node or proxy service

## Install

1. Download `ClashBrowser-v1.13.0-arm64-v8a.apk` from the assets below.
2. Allow installation from unknown sources for your file manager/browser.
3. Install and open the app. The proxy core starts automatically.
4. Tap the status dot (top right), paste your subscription URL and update it.
5. Pick a node and switch the run mode as needed.

Upgrades must be installed over the previous version with the same signing key;
do not uninstall/reinstall if you want to keep your data.

## Notes and known limitations

- The app proxies only its own WebView; other apps are not affected. This is by
  design and is why no VPN service is involved.
- Subscription downloads currently go directly, so the subscription URL itself
  must be reachable without a proxy.
- Incognito mode only stops history recording; it does not isolate cookies,
  cache or the tab snapshot.
- Non-image downloads, file upload, in-page find and search-engine selection are
  not implemented.
- DRM playback depends on the system WebView / Widevine. On devices without a
  usable CDM the player falls back to unencrypted streams.
- The mihomo core and Geo databases are downloaded at build time, so the exact
  core revision is whatever upstream published when this release was built.
- This release is arm64-v8a only.
