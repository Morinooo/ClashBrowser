# ClashBrowser v1.13.2

> 版本梳理：本 release 由旧 tag v1.6.9 重命名而来；APK 由原 commit 代码快照重建，
> versionName 已同步为 1.13.2（versionCode 20 不变）。新旧编号对照见 CHANGELOG。

Hardening release: closes the remaining review findings on top of v1.13.1.

## What's fixed

- **Proxy self-loop guard**: imported subscriptions / local YAML that contain a
  proxy node pointing at the local mixed port (`127.0.0.1`, `localhost`, `::1`,
  `0.0.0.0` on port 7890) are rejected with a clear error instead of looping
  traffic back into the core.
- **Port conflicts**: `port` and `socks-port` are normalized to 0 together with
  `mixed-port: 7890`, so imported configs cannot collide with the WebView
  proxy listener or the controller channel.
- **License attribution**: NOTICE now states mihomo's actual license
  (GPL-3.0) and links the upstream LICENSE instead of embedding an MIT text.

## What's added

- JVM unit tests (ad blocker rules, config validation, address parsing) run in
  CI on every push / pull request.
- Android lint runs in CI with a committed baseline (`app/lint-baseline.xml`):
  pre-existing findings are recorded, any new lint error fails the build.

Everything else is unchanged from v1.13.1.

## Requirements

- Android **8.0 (API 26)** or newer
- **arm64-v8a** device
- An up-to-date Android System WebView
- Your own Clash-compatible subscription or configuration

## Install

1. Download `ClashBrowser-v1.13.2-arm64-v8a.apk` from the assets below.
2. Install over the previous version **signed with the same key**; keep data by
   not uninstalling first.
3. Verify with `sha256sum -c SHA256SUMS`.

## Signing

Signed by the same project release key as v1.13.0 / v1.13.1 (SHA384withRSA,
RSA 4096). Debug builds distributed outside GitHub Releases use a different
signature and cannot be upgraded to/from release builds in place.
