# ClashBrowser v1.13.1

> 版本梳理：本 release 由旧 tag v1.6.8 重命名而来；APK 为原 commit 代码快照，
> 包内 versionName 仍为 1.6.8（versionCode 19）。新旧编号对照见 CHANGELOG。

Fix-only release on top of v1.13.0: closes a proxy fail-open gap where a failed
core start could leave the "proxy enabled" switch on while WebView traffic
actually went direct.

## What's fixed

- The enabled preference is persisted **only after** the mihomo core is running
  and the WebView proxy override is applied. If either step fails, the switch
  rolls back and a toast states that traffic is direct.
- Cold start and resume-to-foreground core failures roll back the enabled
  preference and notify, instead of silently staying "enabled".
- The proxy switch and the in-page banner now reflect the actual running state
  (core stopped / proxy not ready), distinguishing "wants proxy" from
  "proxy actually running". When the core is stopped the banner says requests
  are paused until recovery, not that traffic is direct.

Everything else is unchanged from v1.13.0.

## Requirements

- Android **8.0 (API 26)** or newer
- **arm64-v8a** device
- An up-to-date Android System WebView
- Your own Clash-compatible subscription or configuration

## Install

1. Download `ClashBrowser-v1.13.1-arm64-v8a.apk` from the assets below.
2. Install over the previous version **signed with the same key**; keep data by
   not uninstalling first.
3. Verify with `sha256sum -c SHA256SUMS`.

## Signing

Signed by the same project release key as v1.13.0 (SHA384withRSA, RSA 4096).
Debug builds distributed outside GitHub Releases use a different signature and
cannot be upgraded to/from this release build in place.
