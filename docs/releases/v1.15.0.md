# ClashBrowser v1.15.0

- versionName: `1.15.0`
- versionCode: `22`
- minSdk 26 / targetSdk 34 / arm64-v8a

## Added

### In-page find
- Top-bar search icon opens a find bar replacing the address bar: live match
  count via `WebView.setFindListener`, `findAllAsync` on input, prev/next via
  `findNext`, close clears matches; switching tabs clears highlights.

### Reader mode
- Toolbox → 阅读模式 extracts the article from a **cloned** DOM (script/style/
  nav/aside/footer/header/form/button/svg removed; article/[role=main]/main
  preferred) without touching the live page; paragraphs capped (600 × 2000 ch).
- Full-screen clean reader overlay with font size 12–26 sp and theme-following
  colors; exit via close button.

### Media sniffer
- `shouldInterceptRequest` records media/stream URLs per tab by extension
  (m3u8/mpd/mp4/m4s/ts/flv/webm/mkv/mp3/m4a/aac/ogg/wav), dedup, cap 200.
- Toolbox → 资源嗅探 lists kind + time + URL with copy / download (hands off to
  the download manager) / open-with (video/* audio/* intent); confirmed clear.
- URL metadata only; no response bodies read, nothing written to disk.

### Settings consolidated in Toolbox → More
- Search engine: Google / Bing / Baidu / DuckDuckGo; address-bar and home-box
  non-URL input uses the chosen engine (`engineSearchUrl`, unit-testable).
- Desktop mode: desktop UA + viewport meta overridden to `width=1024`
  (wide-view-port + overview already on) → real desktop layout; toggle reloads
  all live tabs. Former 浏览器标识 page removed.
- Incognito isolation: incognito tabs use LOAD_NO_CACHE, no form data, no
  history, no session snapshot; visited hosts tracked by IncognitoGuard; on
  exit (switch off or last incognito tab closed) their cookies are expired
  (path + domain variants) and WebView cache cleared. Normal-tab cookies
  untouched. Main-page incognito switch moved here.
- Subscription info: active profile's upload/download/total/expire/updated with
  manual refresh (re-fetch subscription); parsing hardened (case, spaces,
  quotes, missing/invalid fields, ms timestamps, negative clamp) + 5 new JVM
  tests (UserinfoTest).
