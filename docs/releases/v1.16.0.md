## Added

### Address-bar search suggestions / autocomplete
- While the address bar is focused and non-empty, a dropdown lists local
  history/bookmark matches (title or URL contains the query, case-insensitive)
  plus up to 5 remote suggestions from the current engine's suggest endpoint:
  Google `suggestqueries.google.com/complete/search?client=firefox`,
  Bing `api.bing.com/osjson.aspx`, Baidu `www.baidu.com/sugrec?prod=pc`,
  DuckDuckGo `duckduckgo.com/ac/?type=list`.
- 250 ms debounce; each keystroke cancels the previous coroutine (including the
  in-flight request); total cap 8 rows; tapping loads the URL or runs the search.
- Incognito sessions show no suggestions; toggle in Toolbox → More (default on).
- Suggest requests use the same direct OkHttp channel as subscription fetches;
  parsing is pure-function and unit-tested (SuggestTest, 5 cases).

### Geolocation API (location permission)
- Manifest gains ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION; requested at
  runtime only after the user allows a specific origin.
- `onGeolocationPermissionsShowPrompt` opens an origin dialog (allow / deny +
  "remember this choice"); remembered decisions auto-apply on later visits
  (GeoStore, JSON in geo_prefs). `onGeolocationPermissionsHidePrompt` cancels.
- Runtime permission denial revokes a stored allow and invokes the WebView
  callback with false; allow invokes with true only after system grant.
- Toolbox → More → 定位权限记录 lists per-origin decisions with per-row delete
  and clear-all, both behind confirmation dialogs.
