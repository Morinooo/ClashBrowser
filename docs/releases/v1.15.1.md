# ClashBrowser v1.15.1

- versionName: `1.15.1`
- versionCode: `23`
- minSdk 26 / targetSdk 34 / arm64-v8a

## Fixed

### Long-press in web input fields
- `WebView.setOnLongClickListener` now returns false for `EDIT_TEXT_TYPE` hit
  results, so input fields and contenteditable nodes get the native selection /
  select-all / cut / copy / paste action mode instead of the custom link/image
  context menu. Plain-text and link/image long-press behavior is unchanged.

### Subscription URL paste
- The subscription field in the proxy panel gains a trailing paste button that
  reads the clipboard (`ClipboardManager.primaryClip`, coerceToText) and fills
  the field; toasts confirm paste or empty clipboard. Native long-press paste
  is left intact for devices where the floating toolbar works.

## Changed

### Dismissible status banner
- The top banner shown when proxy is off / core not running / proxy not ready
  now has a close (✕) button on the right. Dismissal lasts until the proxy /
  core / readiness state changes again (`LaunchedEffect` resets the flag).

### Toolbox layout
- 阅读模式 and 资源嗅探 moved from the toolbox main list into Toolbox → More.
- 浏览器标识 restored as a standalone main-list entry with its own page
  (mobile / desktop UA options; desktop also enables the 1024-wide viewport);
  the desktop switch inside More was removed to avoid duplicate entries.
  Switching reloads all live tabs as before.

## Notes

- Patch release per semver: bug fixes and UI detail tweaks only; no new
  protocols, no breaking changes. `versionCode` continues monotonic (23).
